# SJ Education Website

A responsive, ready-to-use static website for the SJ Education Facebook page.

## Files
- index.html — website structure/content
- style.css — responsive design and styling
- script.js — mobile menu, quiz, animations and share button

## Customize your Facebook link
Open `index.html`, find:
`href="#" id="facebookBtn"`
and replace `#` with your actual Facebook Page URL.

## Run
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. To publish, upload the three files to any static hosting service.

No server, database, or build step is required.
